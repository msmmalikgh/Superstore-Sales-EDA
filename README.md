# 📊 Superstore Sales & Profit EDA

## 📌 Objective
Analyze sales, profit, discounts, and shipping strategies to uncover key business insights.

## 🛠 Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## 📂 Dataset
Sample Superstore Dataset


## 🔍 Key Insights
- Standard Class dominates both sales and profit
- Office Supplies is the top-performing category
- High discounts (>30%) often lead to losses
- West region is the most profitable
